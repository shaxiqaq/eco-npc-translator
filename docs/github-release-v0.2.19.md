## 0.2.19

相对上一版正式发布 `v0.2.16` 的累计更新：

- NPC 翻译自动识别英/日/印尼文，提示词按源语言切换
- 共享词库按源语言分桶（`zh-CN` / `zh-CN-ja` / `zh-CN-id`），短选项不再上报
- 采集记录源语言；EventID 对照只落盘，不按句序套用以免错句
- 修复安装包 NPC 翻译缺少标准库 `uuid`、启动即崩溃
- 安装包补上统一采集代理，翻译和伤害采集共用一次挂接
- 更新弹窗把 GitHub HTML 转成可读说明，下载进度显示 MB
- 状态悬浮窗只接收倒计时所需字段，刷图时更轻
- 技能名不再跟着整包战斗快照刷新
- 主进程按域拆 IPC；伤害包走分派表

完整对比：https://github.com/shaxiqaq/eco-npc-translator/compare/v0.2.16...v0.2.19
