# 小雅原生重写

## 当前状态

工具箱已经默认使用自研的 `XiaoyaCore.exe`，不再从“小雅助手”页面启动原版 `小雅.exe`。

当前核心版本为 `0.2.0`，运行模式为 `native-background`，已经构建为
Windows x86 自包含单文件，并通过无害窗口探针对照测试：

- 以自包含的 Windows x86 单文件发布；
- 使用 JSON Lines 与 Electron 主进程通信；
- 支持父进程退出守护；
- 导入旧版 GBK INI，并迁移为用户数据目录中的 JSON；
- 只连接 Electron 明确传入的目标 PID，不会自行扫描并命中其他 ECO；
- 按六组独立间隔向目标窗口后台发送 F1–F6；
- 按配置在技能键后发送当前鼠标位置对应的后台左键点击；
- 在完整按键/鼠标动作后执行技能后延迟；
- 启动和停止时执行已确认的 `Ctrl+T` SS 模式切换；
- 目标窗口失效后自动退出运行状态；
- 支持启动、暂停、停止、配置热更新和安全退出。

原版 EXE 暂时保留在安装资源中，仅用于行为对照和紧急回退。当前工具箱不会执行它。

本轮构建：

- PE 架构：`0x014C`（x86）；
- 文件大小：63,020,114 字节；
- SHA-256：`92B6AD8E502F2BE8AB5C35D6EC60E2C0018DD08CF951A66A893D80B9200F009E`。

## IPC 协议

Electron 发送：

```json
{"id":1,"command":"configure","payload":{"targetPid":44932,"skills":[]}}
{"id":2,"command":"start","payload":{}}
{"id":3,"command":"stop","payload":{}}
{"id":4,"command":"shutdown","payload":{}}
```

核心响应：

```json
{"id":1,"type":"response","ok":true,"payload":{}}
```

核心主动事件：

```json
{"type":"event","event":"action","key":"F1","mouse":true,"delay":2500}
```

## 静态分析进展

静态分析现已确认：

- 原程序标题为“小雅专用ECO后台按键”；
- 六行是按计时周期自动向选中的 ECO 窗口发送 F1～F6，不是监听用户按下 F1～F6；
- “技能时间”实际是技能间隔，单位为秒；
- “鼠标”表示按键后追加后台左键单击；
- “延迟时间”在界面中称为“技能后延迟”，单位为毫秒；
- 支持选择 ECO 进程、沙盘双开、开始/停止、隐藏/显示游戏窗口和保存配置；
- 目标进程失效后会自动退出运行状态。

完整证据、三次动态观察结果和仍需确认的项目见
[小雅行为分析](./小雅静态行为分析.md)。
